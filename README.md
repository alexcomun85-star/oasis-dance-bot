# Бот шоу-балета Oasis Dance — @oasisdance_show_bot

Чистая версия бота из Replit (проект `TelegramBotHelper`), подготовленная для работы на своём сервере (VPS).

## Что умеет
- Главное меню: заказ выступления, видео, контакты, Instagram, ВКонтакте, сотрудничество.
- Пошаговая форма заявки → заявка приходит администраторам в Telegram и сохраняется в `data/orders.jsonl`.
- ИИ-ассистент на Google Gemini (включается, если указан `GEMINI_API_KEY`).
- Команда `/myid` показывает ваш Telegram ID (нужен для `ADMIN_CHAT_IDS`).

## Перенос на сервер — пошагово

### Шаг 0. Подготовка
1. В Replit откройте проект **TelegramBotHelper** → **Tools → Secrets** и скопируйте значения
   `TELEGRAM_BOT_TOKEN` и (если есть) `GEMINI_API_KEY`.
   Если токена там нет — в Telegram напишите @BotFather → `/mybots` → @oasisdance_show_bot → **API Token**.
2. **Остановите бота в Replit** (кнопка Stop и, если есть, удалите Deployment). Две копии бота одновременно
   работать не могут: Telegram отдаёт сообщения только одной (ошибка 409).

### Шаг 1. Залить файлы на сервер
С компьютера (Терминал на Mac), из папки, где лежит архив:
```
scp oasis-bot.zip root@IP_СЕРВЕРА:/root/
```

### Шаг 2. Подключиться к серверу и установить
```
ssh root@IP_СЕРВЕРА
apt-get install -y unzip
unzip -o oasis-bot.zip -d oasis-bot && cd oasis-bot
bash install.sh
```
Скрипт спросит токен бота и ключ Gemini, установит всё и запустит бота как службу
(бот сам перезапускается при сбое и после перезагрузки сервера).

### Шаг 3. Проверить
- Напишите боту `/start` — должно появиться меню.
- Напишите `/myid`, впишите полученный номер в `ADMIN_CHAT_IDS`:
  ```
  nano /opt/oasis-bot/.env
  systemctl restart oasis-bot
  ```
- Оформите тестовую заявку — она должна прийти вам.

## Обслуживание
| Что сделать | Команда |
|---|---|
| Журнал в реальном времени | `journalctl -u oasis-bot -f` |
| Перезапустить | `systemctl restart oasis-bot` |
| Остановить | `systemctl stop oasis-bot` |
| Изменить контакты/ключи | `nano /opt/oasis-bot/.env`, затем перезапуск |
| Посмотреть заявки | `cat /opt/oasis-bot/data/orders.jsonl` |

Обновление кода: заменить `.py`-файлы в `/opt/oasis-bot/` и выполнить `systemctl restart oasis-bot`
(или повторно запустить `bash install.sh` — настройки в `.env` сохранятся).

## Требования к серверу
- Ubuntu 20.04+ или Debian 11+, от 512 МБ памяти; бот почти не нагружает сервер.
- С сервера должен открываться `api.telegram.org`; для ассистента — `generativelanguage.googleapis.com`
  (Google Gemini недоступен с российских IP — для ассистента нужен сервер за пределами РФ).
  Проверка: `curl -sI https://api.telegram.org | head -1`.

## Что изменено по сравнению с Replit
- Оставлен только рабочий бот (в Replit было ~100 файлов разных версий, панель Flask и «сторожа»).
- Исправлено: кнопки выбора программы не отправлялись (длина `callback_data` больше 64 байт);
  уведомления о заявках не доходили администраторам (неверный разбор `ADMIN_CHAT_IDS`, заявки
  «сохранялись» в неподключённую базу); `/cancel` не отменял форму; текст ИИ и данные клиентов
  ломали HTML-разметку.
- Ассистент переведён с устаревшей библиотеки и выведенной из эксплуатации модели `gemini-1.5-flash`
  на REST API и псевдоним `gemini-flash-latest`.
- Убраны выдуманные контакты (`oasisdance@example.com`, `+7 (123) 456-78-90`): телефон и email задаются в `.env`.
